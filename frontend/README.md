# 📊 HappyFox Nexus - Rule-Based Resume Parser & AI Shortlister



### Frontend Setup

1. **Navigate to frontend directory**
```bash
cd ../frontend
```

2. **Install Node.js dependencies**
```bash
npm install
```

3. **Start development server**
```bash
npm run dev
```
Frontend application available at `http://localhost:5173`
